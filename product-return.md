# Customer Purchase & Return Scenarios

## Order Details

Customer purchases:

- XL Size: 1 item
- S Size: 1 item

## Delivery Scenarios

### Case 1: Product Return During Delivery

When the driver delivers the order to the customer, the customer may decide to return some or all items.

Examples:

- Customer keeps the S size item and returns the XL size item.
- Customer returns both the XL and S size items.
- The driver collects the returned items and brings them back to the shop.
- The system should record the quantity and reason for each returned item.

### Case 2: Size Exchange Request

Before or during delivery, the customer may contact the shop and request a size change.

Examples:

- Change from XL to L.
- Change from S to M.

The system should:

- Record the original order details.
- Record the requested size change.
- Update the delivery information accordingly.
- Maintain a history of all changes for tracking and reporting purposes.
